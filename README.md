# Sky PC Auto Music

Sky PC Auto Music 是一款用于在游戏 Sky: Children of the Light 中自动弹奏乐器的软件。

## 功能

- 能够读取 Sky Studio 制作的乐谱
- 支持暂停，进度控制，倍速控制
- 能够批量导入乐谱，支持拖拽导入与递归导入子文件夹
- 能够合并相邻节拍相同音节，更好支持延音乐器
- 支持键盘键位自定义，适配非 US 布局
- 自动记住播放列表，下次启动直接恢复
- 支持全局热键控制播放与切歌
- 内置曲谱市场，可搜索、单个或按分类批量下载并导入 Sky1984 曲库
